# Maryjane-JQUERY
Maryjane E-Commerce is a full-stack clothing e-commerce web application designed to provide a clean, intuitive, and user-friendly shopping experience. The platform focuses on simplifying product discovery, allowing users to browse clothing collections and save their favorite items through a personalized wishlist feature.

This project was developed independently as a full-stack application to explore e-commerce workflows and user experience design. Inspired by the idea that online shopping should be straightforward and accessible, Maryjane emphasizes simplicity, responsive design, and an uncluttered interface to help users find products efficiently.
